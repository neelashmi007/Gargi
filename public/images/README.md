# Photos & Images for "A Little Universe for Gargi"

Add your photos of Gargi and shared memories into the subdirectories here!

## Subdirectories:
- `public/images/gallery/`: Put gallery photos here.
  - Recommended names: `photo-1.jpg`, `photo-2.jpg`, etc.
  - To customize titles, captions, dates, and categories, edit `src/data/gallery.ts`.
- `public/images/memories/`: Put timeline and scrapbook memories here.
  - Recommended names: `memory-1.jpg`, `memory-2.jpg`, etc.
  - To customize titles, notes, and chapters, edit `src/data/memories.ts`.

## Missing Image Protection:
The website has graceful SVG/CSS fallback placeholders. If an image file is not present yet, it displays an aesthetic, fairycore placeholder with a tender prompt, so the website looks gorgeous right out of the box and never crashes!

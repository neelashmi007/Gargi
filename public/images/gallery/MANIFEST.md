To populate the Gallery with your real photographs, place your image files directly into this folder (`public/images/gallery/`).

The website automatically detects each photo. When an image file is added, it displays in high resolution; until an image file is placed, it displays an aesthetic, fairycore polaroid keepsake placeholder frame.
